# Agile Tracker

Veebirakendus agiilse tarkvaraprojekti kasutajalugude (*story*'de) haldamiseks
Kanban-laual. Koolitöö (VIKK).

> 🚧 README täieneb arenduse käigus (vt issue *Dokumentatsioon ja README*).

## Lühidalt

Kolm veergu — **Todo / Backlog**, **Doing**, **Done** — kuhu saab luua, muuta,
kustutada ja lohistada story'sid. Backlogi järjekorda saab hiirega muuta ja see
säilib pärast lehe uuendamist. Andmeid haldab REST API.

Tehnoloogiad: **Node.js + Express**, vanilla JS / HTML / CSS, andmed JSON-failis.
